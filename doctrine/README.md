# Doctrine

The universal laws. Independent of model, vendor, or year.

If you only have time for one section of this book, read this one.

| Chapter | One line |
| --- | --- |
| [01 — Agent = Model + Harness](01-agent-equals-model-plus-harness.md) | The model is rented. The harness is yours. |
| [02 — Humans steer, agents execute](02-humans-steer-agents-execute.md) | Specify intent. Build feedback. Stay out of the loop. |
| [03 — Context is a scarce resource](03-context-is-scarce.md) | Tokens are a budget. Spend them on signal. |
| [04 — Guides and sensors](04-guides-and-sensors.md) | Anticipate before. Correct after. Both, always. |
| [05 — Invariants over instructions](05-invariants-over-instructions.md) | Enforce what must be true. Let the agent choose how. |
| [06 — Tools are a contract](06-tools-are-a-contract.md) | A tool is a contract between deterministic systems and a non-deterministic caller. |
| [07 — The eval is the product](07-the-eval-is-the-product.md) | No eval, no feature. Look at the data. |
| [08 — The loop](08-the-loop.md) | Loops compound. Heroics don't. |
| [09 — Memory and amnesia](09-memory-and-amnesia.md) | The agent forgets. The harness remembers. |
| [10 — Trust boundaries](10-trust-boundaries.md) | Assume injection. Design for it. |

The doctrine chapters are short on purpose. Each one is meant to be read in
under five minutes and re-read in under one.
