# Three harnesses

The doctrine holds across every coding agent. The grain does not. Each
harness has its own anatomy, its own idioms, and its own places to spend
your attention.

| Harness | Origin | Core conviction | Surface |
| --- | --- | --- | --- |
| [**Codex**](codex.md) | OpenAI | Map, not manual. Loops, not heroics. | App · CLI · Cloud · SDK |
| [**Claude Code**](claude-code.md) | Anthropic | The harness is a programmable companion. | CLI · IDE · Skills · SDK |
| [**Pi**](pi.md) | Mario Zechner | Primitives, not features. Adapt the harness. | CLI · RPC · SDK |

Read them in any order. They are siblings, not rivals.

The differences are real but smaller than they look. Codex leans toward
*long-running cloud agents with strict invariants*. Claude Code leans toward
*persistent local pair-programming with first-class skills*. Pi leans toward
*minimal, hackable, build-it-yourself*. Pick the one that matches the work.
Then steal good ideas from the other two.
