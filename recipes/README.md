# Recipes

Copy-pasteable workflows. Each recipe is a sequence of moves that has worked
in production for someone — usually for many someones. Adapt freely. Don't
worship.

| Recipe | What you get |
| --- | --- |
| [01 — Bootstrap a greenfield repo](01-bootstrap-greenfield.md) | A repo Codex/Claude can drive from day one. |
| [02 — Onboard an agent to a legacy codebase](02-onboard-legacy.md) | Walk an agent through a 100k-LOC repo without drowning it. |
| [03 — Build an eval suite from zero](03-build-eval-suite.md) | Hamel's pyramid, applied to a coding agent. |
| [04 — Multi-agent code review](04-agent-review.md) | Two agents and the Ralph Wiggum Loop. |
| [05 — Triage + fix loop](05-triage-and-fix.md) | Bug report → repro → fix → PR, with the agent driving. |
| [06 — Skill authoring](06-skill-authoring.md) | Build a skill that compounds. |
| [07 — Long-horizon task with checkpoints](07-long-horizon.md) | A six-hour run that doesn't go off the rails. |

Recipes are deliberately concrete. If a step doesn't apply to your harness,
translate it. The doctrine generalizes; the syntax does not.
